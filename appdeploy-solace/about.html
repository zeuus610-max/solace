Engineering Architecture

Built to Protect.

SOLACE is an end-to-end URL threat detection and machine-learning intelligence platform engineered to eliminate drive-by risks and unmask deception in real time.

The Problem with Traditional Blacklists

Conventional anti-phishing safeguards rely on public threat intelligence feeds and reputation blacklists. By the time a domain is reported, indexed, and distributed, targeted victims have already submitted credentials.

SOLACE takes a zero-execution approach. By analyzing URL structure, lexical character entropy, token combinations, and structural depth, our ensemble detects attacker patterns at inception—before a domain even gains reputation history.

Core Safety Guarantee
Zero Target Connection

SOLACE never performs HTTP GET requests, follows redirects, renders DOM trees, or runs remote JavaScript. Every computation happens strictly within our local feature extraction pipeline.

Explainable AI (XAI)

14-Dimensional Heuristic Vector

Every scanned link is tokenized into 14 mathematical indicators that feed the supervised Random Forest ensemble.

Shannon Entropy

Calculates randomness in host character distribution to catch algorithmically generated domains (DGA).

Subdomain Nesting

Measures hierarchical depth (e.g., paypal.com.account-update.xyz) used to disguise malicious second-level hosts.

Lexical Lure Tokens

Detects brand names paired with high-urgency keywords such as login, verify, confirm, kyc, and invoice.

Raw IP Addressing

Identifies direct IPv4/IPv6 destination addressing that bypasses standard DNS infrastructure.

Credential Obfuscation

Flags the presence of @ symbols which browsers interpret as basic auth, masking the true host.

Abuse TLD Heuristics

Evaluates registrars with statistically disproportionate rates of disposable, burner phishing campaigns.

Model Transparency & Advisory

SOLACE’s initial model is trained on a reproducible synthetic corpus combined with established lexical heuristic benchmarks. While it achieves high statistical F1-scores on held-out test splits, machine-learning URL scores should be treated as intelligent risk indicators rather than absolute security guarantees. Users should always exercise zero-trust diligence when interacting with untrusted communications.
