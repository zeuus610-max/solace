Feature Vector Assembly

Anatomy of Deception: 4 Core URL Manipulation Techniques

1. Typosquatting & Homographs

Attackers register lookalike domains using visual character substitutions (e.g., rn instead of m, 0 for o, or Cyrillic Unicode characters via IDN Punycode) and extra hyphens.

✓ microsoft.com
✗ rnicrosoft-support.com

2. Subdomain Nesting Abuse

Because users read URLs left-to-right, attackers place legitimate brand names as subdomains on the left while hiding their actual malicious root domain on the far right before the first single slash /.

✓ login.paypal.com/myaccount
✗ paypal.com.verify-id.ru/login

3. '@' Symbol Credential Trick

Per RFC 3986 URI syntax (http://user@host), everything before the @ symbol is treated as a username and ignored for routing; the browser actually navigates to the host after @.

https://google.com@evil-phish.xyz
→ Resolves to: evil-phish.xyz

4. Open Redirects & Shorteners

Abusing URL shorteners (bit.ly) or unvalidated ?redirect= parameters on trusted websites to bypass email gateway filters and forward victims to external phishing kits.

! trusted.org/login?next=http://phish.tk
✗ bit.ly/3x9KpL2-claim-bonus
